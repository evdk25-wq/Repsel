# Changelog

All notable changes to Repsel are documented in this file.

## 1.1.0 — Red Baron

- Added synchronized source and rendered preview modes.
- Added configurable document typography and font discovery on Linux.
- Added embedded local image insertion with compact source placeholders.
- Expanded the Edit menu with standard document commands.
- Improved editor dimensions, themes, and visual contrast.
- Improved PDF pagination for headings, lists, formulas, tables, and code blocks.
- Fixed scroll synchronization between the source and preview panes.
- Removed redundant document status messages from the interface.

## 1.0.1

- First public Linux release with Debian and AppImage packages.
